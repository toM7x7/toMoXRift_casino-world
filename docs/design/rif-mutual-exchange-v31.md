# RIF ⇄ カジノコイン 相互交換設計 v31（v33へ更新済み）

> 2026-08-28に管理側承認を受け、実装仕様は `casino-economy-mutual-v33.md` へ移行しました。以下は合意前の設計履歴です。

## 結論

固定レート `1 RIF = 50カジノコイン` の両方向交換はv33で実装済みです。旧残高をbonusへ移行し、RIF入金と監査済みゲームの原資連動払戻だけをredeemableとして扱います。

## v2固定レートと初期上限

| 項目 | v2初期値 |
| --- | ---: |
| RIF → カジノ | 1 RIF → 換金可能50枚 |
| カジノ → RIF | 換金可能50枚 → 1 RIF |
| 出金最低 | 50枚 / 1 RIF |
| 1回交換上限 | 250枚 / 5 RIF |
| 1日上限 | 入金・出金の合計250枚相当 / 5 RIF |
| 交換手数料 | 0% |

50はRIFと遊技チップの単位を分けるためのデノミネーションです。レート自体には手数料を混ぜません。初期の安全弁は3 RIF/回、5 RIF/日とし、実績を見て設定値だけ変更できるよう中央設定に集約します。

## 残高を二つに分ける

- `redeemable`: RIF入金で得たコインと、そのコインを賭けて得た払戻。50枚単位でRIFへ戻せる。
- `bonus`: 既存残高、受付の救済10枚、運営配布、キャンペーン報酬、初版のユーザー間移転。遊技には使えるがRIFへ戻せない。
- 払戻は賭け元と同じbucketへ返す。混合賭けを許す場合は、使用比率で払戻を按分する。
- v2開始時に旧残高を50倍しない。枚数を変えずに`bonus`へ分類する。これで過去に稼ぎやすかった残高がRIFへ流出しない。

## RIF準備金

世界から付与できるRIFは、同じ世界が交換所で受け取ったRIFの範囲に制限します。

```text
availableReserveRif = totalRifDeposited - totalRifGranted - pendingReservedRif
```

出金受付時に共有KVの準備金を原子的に予約し、負数になった要求は拒否します。RIF付与が失敗した場合は同じ`clientTransactionId`で再試行し、最終失敗時だけ予約を戻します。同一ユーザーの複数インスタンス参加ができなくても、別ユーザー同士の同時出金は起こるため、準備金予約は必要です。

## ゲーム経済への影響

固定レートなので、換金可能コインをRIFへ戻したときの期待比率は各ゲームのRTPと同じです。例えばRTP95%のゲームを長期で遊べば、RIF準備金の期待残高は約5%ずつ増えます。厳格さは不透明な往復差ではなく、明示したハウスエッジと小額出金上限で作ります。

bonusだけで遊ぶ利用者はRIF準備金へ影響しません。カジノ自体は無料の救済コインでも遊べるため、RIFを持たない利用者の体験も維持できます。

## 逆交換の状態機械

```text
見積・ユーザー確定
  → player KVにpending(created)
  → redeemable残高と日次上限を再確認
  → shared KVでRIF準備金を原子的に予約
  → redeemableカジノコインを減算
  → pending(casino-debited)
  → RIFCoin grant（同じclientTransactionIdを再利用）
  → pending(rif-granted)
  → 準備金予約を確定・レシート保存・pending削除
```

RIFCoin v0.1の現行`main`（確認時commit `86c5bbd`）には、残高取得、負数決済、正数付与、`worldId + clientTransactionId`による冪等処理があります。World StorageとRIFCoin APIを一つのDBトランザクションにはできないため、pending journalと管理者照合は残します。

## 有効化条件

1. walletを`redeemable`と`bonus`へ移行する。
2. RIF入金時の換金可能残高と準備金加算を同じ台帳へ記録する。
3. 逆交換pending、原子的な準備金予約、失敗時補償を実装する。
4. 管理区画へ準備金、pending、付与済みRIF、日次上限の照合画面を追加する。
5. N-JELLYと50:1レート、付与上限、reason、metadataを合意する。
6. 別ユーザー同時出金、通信中断、リロード、RIF付与の冪等再試行を受入試験する。

現段階では相談用設計だけを保存し、配布コードには`grant()`、v2逆交換見積、出金UIを含めません。合意後に別リリースとして実装します。
