# ワールド増築 実装記録 v18

## 実装した建築

- A区画を縦置きの「船長の運命盤」へ置換。正面は既存広場側（+Z）で、盤面、指針、幅7.2mの傾斜BET卓を同時に見られる。
- B区画を8人用の八角形投票広場へ置換。中央卓の周囲に8つのENTRY位置を等間隔で設けた。
- B区画から幅4m、長さ3m、上昇0.6m（勾配1:5）の短いスロープを通り、8人が自由に並べる観覧デッキへ接続した。
- 観覧デッキの東側に50mの4レーンコースを南北へ並列配置。デッキからSTARTとGOALを同一視野に収める。
- 競走路は観覧床より1.35m下げ、水平線に潰れず4本のレーン面が読める約7度の俯角を確保する。
- 柵際は迫力優先、デッキ西寄りの「全景ライン」はSTART/GOAL同時確認用とし、自由移動の中で視野角を選べる。
- コースとデッキの間は16m以上離し、コースにはコライダーを置かない。プレイヤーが競走路へ迷い込まず、遠景として読む構成とした。

## 視認性と3D UI

- 既存メイン広場からA/B区画へ幅3mの色分け導線を追加。
- スポーン地図の「建設予定」を「A 運命盤」「B ダービー」に更新。
- 浮遊ボタンを廃し、色／出走枠、チップ山、投票券、確定操作、抽選／発走操作を傾斜した実物BET卓へ統合した。
- 各選択肢には全プレイヤーの合計掛け金を表示し、自分の未確定選択は「仮置き／仮票」、確定後は「BET札／投票券」として卓上に残す。
- 黄色・金色の選択枠は濃色文字に切り替え、色だけに依存せず番号・名称・合計枚数でも判別できる。
- ダービー操作は投票広場、観戦はデッキに分離し、観戦中の中央UI遮蔽を避ける。

## 現在の動作範囲

- 運命盤は8色を直接選択し、1・3・5枚からBET。最大8人の賭けを `useInstanceState` で共有し、締切後に正式抽選する。的中時は賭け金×8を払戻す。
- ダービーの8つの外周枠は参加者表示専用。賭け先は中央卓の4魔獣から選び、1・3・5枚をBETする。的中時は賭け金×4を払戻す。
- ダービーのHippogriffはレーン干渉を避けるため、モデルスケールを0.1から0.072へ縮小した。
- 払戻は各プレイヤーのWorld Storageコインへ反映し、ラウンドトークンを保存して同一端末の再読込による二重払戻を抑止する。
- 結果生成とラウンド進行はインスタンス同期であり、専用サーバーによる完全な不正防止は今後のゲート。

## 音響

- 専用の24秒ループBGMと、選択・BET・回転・発走・勝利・敗北の効果音を同梱。
- ブラウザの自動再生制約に合わせ、最初のゲーム操作またはスポーン付近の3D BGMボタンで音を開始する。
- WAVは `scripts/generate-casino-audio.mjs` から生成するオリジナル音源で、外部ライセンス素材は使用していない。
