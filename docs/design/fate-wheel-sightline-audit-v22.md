# 船長の運命盤 8視点監査 v22

実施日: 2026-08-15

## 監査範囲

- 現行の8色床パッド位置を、プレイヤーの目線高1.6mとして検証した。
- カメラは各パッド中心から円盤中心を向き、FOVは75度に統一した。
- 色パッド自体の押しやすさではなく、「その賭け場所に残って抽選を見る」時の円盤視認性を判定した。
- 正面中央のレビューカメラは比較用であり、各賭け場所の合否には使っていない。

現行配置は8位置中0位置が無条件PASS。正面中央だけは良好だが、実際の賭け場所の体験を代表していない。

## 根本原因

1. L1/R1が円盤面より背面側にある。
2. 4色を縦方向ではなく奥行方向へ並べたため、同じゲーム内で観戦距離と角度が大きく変わる。
3. 支持材が盤面の前後をまたぐAフレーム形状で、側面視点では円盤より支持材が大きく見える。
4. 「選択位置」と「抽選観戦位置」が同一なのに、全位置からの視線回廊を定義していない。

## v22本命案: 8連アークキオスク

「各色の場所で賭け、その場から抽選を見る」を文字通り満たすため、左右壁案ではなく円盤正面の低い円弧へ8色を1台ずつ並べる。

- デッキ: 14m x 14m
- 円盤中心: `[0, 3.9, -3.0]`。現行より0.8m後退
- キオスク中心: 円盤地上中心から半径7.0m、角度 `[-42,-30,-18,-6,6,18,30,42]` 度
- キオスク座標: `[-4.684,2.202]`, `[-3.500,3.062]`, `[-2.163,3.657]`, `[-0.732,3.962]`, `[0.732,3.962]`, `[2.163,3.657]`, `[3.500,3.062]`, `[4.684,2.202]`
- 目線位置: 半径8.2m、y=1.6m
- 目線座標: `[-5.487,3.094]`, `[-4.100,4.101]`, `[-2.534,4.798]`, `[-0.857,5.155]`, `[0.857,5.155]`, `[2.534,4.798]`, `[4.100,4.101]`, `[5.487,3.094]`
- 各キオスクは円盤中心へ正対し、高さ0.85m以下、クリック面1.3m x 0.65m以上
- 円盤支持材は盤面後方へ寄せ、前面へ張り出すAフレームを廃止する

最外位置でも盤面角42度、円盤下端から指針上端まで約43.4度。FOV60でも上下約16.6度の余白を持つ。隣接する目線位置は1.71m離れ、8人が同時に並べる。

v21の左右壁案は、遠隔レイ位置を柵で固定すれば暫定案として成立する。ただし壁の足元へ近づくと盤面角約78度になり再びFAILするため、本命にはしない。

## 実装後の合格条件

1. 8つの目線位置をFOV60で再撮影し、8人アバター配置後も同じ結果になることを確認する。
2. すべての視点で円盤外周、中心軸、白い指針、当選区画を100%表示し、画面端から6度以上の余白を持つ。
3. 支持材が円盤中央90%または指針のシルエットへ交差しない。
4. 盤面角45度以下、円盤の見かけ高さは画面の35%以上。
5. 色覚だけに依存せず、番号と日本語色名で選択・結果を照合できる。
6. キオスク中心への下向き照準角38度以下、隣接プレイヤー間1.5m以上、背面退避路1.5m以上。
7. 抽選開始後の5秒間はキオスクを消灯し、円盤と指針を主役にする。
8. 画面写真だけでは確認できない中心レイの当たり判定、VRでの首振り量、身長差は実機テストを別に行う。
