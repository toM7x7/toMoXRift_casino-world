# 麻雀から「海賊じゃら」への切り替え計画 v19

## 目的

現行麻雀を、麻雀知識がなくても遊べる3枚セット収集型の牌ゲームへ置き換える。公開名は商標名を避けて「海賊じゃら」とし、企画説明上のみ「ドンジャラ風」を使う。

## 切り替え方針

- 現行 `MahjongTable` は完成まで残し、新規 `DonjaraTable` と純粋ルール層 `game/donjara.ts` を並行実装する。
- ルール・NPC・コイン・1〜4人実機QAが通るまで `World.tsx` の参照は切り替えない。
- 切り替え時に地図、遊び方、ワールド説明の「麻雀」を「海賊じゃら」へ一括更新する。
- 旧麻雀はGit履歴から戻せるため、同じ卓に複雑なモード切替スイッチは置かない。

## v1ルール

- 1〜4人。空席はNPCが担当する。
- 12種類×4枚、合計48枚。4色の海賊団×3役職（船長・魔獣・お宝）を基本構成とする。
- 各席へ8枚配り、自分の番に1枚引いて9枚にし、1枚捨てる。
- 9枚が3枚セット×3組になれば「あがり」。
- セットは次の3種。
  - 同じ絵3枚：基本セット。
  - 同じ海賊団の船長・魔獣・お宝：クルーセット。
  - 同じ役職を異なる3海賊団で集める：艦隊セット。
- 自摸完成は「ツモ」、直前の捨て牌で完成する場合は「ロン」。ポン・チー・カンはv1では採用しない。
- 捨て牌後に3秒のロン受付を置き、ロンがなければ次席が自動で引く。
- 山が0枚なら流局。48枚から初期配牌32枚を引くため、最大16巡で必ず終了する。

## コイン設計

- ENTRY時に各人2枚を先払いする。開始前離席のみ返却する。
- NPC席はハウスが2枚相当を加え、毎局のポットは8枚固定とする。
- 人間がツモ／ロンした場合は8枚を受け取る。NPC勝利時は人間のENTRYがハウスへ移る。
- 流局時は人間のENTRYを返却する。
- ロン時の追加直払いはv1では行わず、事前に確定したポットから払戻す。プレイヤー間送金の競合を避けるため。
- `casino.donjara.settled.v1` にラウンドトークンを保存し、再読込による二重払戻を防ぐ。

## 3D UI / UX

- 画面浮遊UIではなく、各席の牌ラックと卓上操作板へ統合する。
- 自分の手牌は自席ラックだけに表示し、他プレイヤーからは裏面牌として見せる。
- 牌は「色＋番号＋大きな絵」の三重符号化とし、画像だけに依存しない。
- クリック対象は牌全体。選択後に牌を3cm持ち上げ、もう一度押すか大きな「この牌を捨てる」で確定する。
- 卓中央に「残り山」「現在手番」「ポット」「ロン受付3秒」を常時表示する。
- 各捨て牌は古い順で最大12枚を表示し、最新牌を発光させる。`slice(-6)` 表示は廃止する。
- 有効時だけ「ツモ」「ロン」を点灯する。ポン・チーの表示は置かない。
- 初心者カードとして完成例3種を卓の外周に常設する。

## 状態モデル

- Instance State: `casino.donjara.table.v1`
- フェーズ: `lobby -> dealing -> drawing -> discard -> ron-window -> settled`
- 必須フィールド: `roundId`, `seats`, `hands`, `wall`, `discards`, `currentSeat`, `lastDiscard`, `ronDeadline`, `winnerSeat`, `winType`, `message`。
- すべての状態遷移を純粋関数化し、UIイベントから直接配列を書き換えない。
- NPC進行はホストだけが実行し、ラウンドID・フェーズ・手番を再確認してから更新する。

## 実装順序

1. 12牌の名称・配色・絵柄を確定し、画像生成用アトラス設計を作る。
2. `game/donjara.ts` に山、配牌、セット分解、ツモ、捨て、ロン候補、流局を実装する。
3. ルール単体テストと状態遷移テストを先に作る。
4. `DonjaraTable.tsx` を現行卓寸法のまま差し替え可能な構造で実装する。
5. NPC思考、3秒ロン受付、途中退出時NPC引継ぎを追加する。
6. ENTRY、8枚ポット、勝利／流局精算と二重精算防止を接続する。
7. 1人＋NPC、2人、3人、4人、退出／再読込を実インスタンスでQAする。
8. `World.tsx` と地図・説明を切り替え、XRiftへ段階リリースする。

## 公開ゲート

- 48枚すべての枚数が保存され、同一牌が5枚以上存在しない。
- 1手番につき引くのは1枚、捨てるのは1枚。山が必ず減り、無限ドローしない。
- すべての有効な3セット構成を判定し、無効な9枚を誤判定しない。
- ロンは直前の捨て牌に対してだけ3秒間有効。
- 他プレイヤーの手牌表面が見えない。
- 敗者はENTRY時点で2枚支払済みで、勝者8枚／流局返却が一度だけ行われる。
- 1〜4人すべてで対局開始から決着、次局、離席まで完走する。

## 現行麻雀から残すもの

- 4席ENTRY、座席固定、X離席、NPC引継ぎ。
- `useInstanceState` による同一インスタンス同期。
- `CasinoEconomy` とWorld Storageによるプレイヤー別コイン。
- 物理卓、NPCモデル、SE/BGM基盤。

## 廃止するもの

- 34種136枚の麻雀牌、順子／刻子／雀頭判定、待ち牌表示。
- 「おすすめ」「ポン」「チー」「カン」など麻雀固有の学習負荷。
- 固定6枚だけを見せる捨て牌表示。
- 人数に関係なく固定6枚を払う現行配当。
