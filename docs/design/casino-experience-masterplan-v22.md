# Neon Casino Club 体験・経済拡張計画 v22

## 企画の核

「勝って残高を増やす」だけでなく、遊ぶほど航海手帳が埋まり、港が育ち、自分の好みの柄や演出が増えるワールドにする。

進行値は3つに分ける。

1. **共通コイン**: 外部サーバーが正本。ワールドやインスタンスを跨ぐ。
2. **カジノコイン**: このワールド内の遊技、参加費、演出、建設基金に使う。
3. **航海名声・実績章**: 購入不能。遊び方の幅と達成で増える。

残高でランクを買わせない。高ランクや外部アイテムが勝率、倍率、手数料を有利にする設計は禁止する。

## 共通コイン交換所

初期は `共通コイン → カジノコイン` の一方向交換だけにする。逆交換、ユーザー間送金、外部アイテム消費は共通規格の仕様と運用責任が確定するまで実装しない。

交換所は浮遊UIではなく、GM受付に隣接した「港の両替所」とする。

- 壁面: 共通残高、カジノ残高、レート、手数料、更新時刻
- 卓上: 大きな交換額札、確認札、取引照会札
- 確認: 支払額、レート版、手数料、受取額、取消条件を一画面で表示
- 完了: 取引番号付きの交換証と短い計数機アニメーション
- 障害: `再試行可能`、`取消済み`、`運営確認中` を区別する
- メンテナンス: 交換所だけを閉じ、既存カジノコインでの遊技は継続可能にする

交換式は最小単位の整数で計算する。

`受取 = floor(支払共通コイン × レート) - 明示手数料`

手数料は仮に1〜3%から検証するが、最終値は流入、遊技払戻、救済配布、吸収量のテレメトリを見て決める。

### 取引状態

`見積作成 → 引落待ち → 引落確認 → カジノ入金待ち → 完了`

取引には、ユーザーID、ワールドID、取引ID、冪等キー、レート版、有効期限を固定する。秘密鍵や管理トークンは配布されるワールドJavaScriptに置かない。

World Storageは表示キャッシュ、実績、ワールド内演出に使えるが、外部共通コインの正本やリアルタイム決済基盤にはしない。同じ交換証の二重入金をサーバー側で拒否する。

- 逆交換、ユーザー間送金、所有アイテム照会の可否

## 航海手帳と港ランク

港ランクは `見習い → 船員 → 航海士 → 船長`。残高ではなく、異なる遊技を理解し、最後まで体験した実績数で上げる。

実績例:

- 初航海: 4遊技を1回ずつ完了
- 21の目利き: BJで「止める」を選び勝利
- 四海の仲間: 海賊じゃらで指定クルーセット完成
- 運命の目撃者: BETから結果表示まで運命盤を観戦
- ゴールの証人: 投票から着順確定までダービーを観戦
- 盛り上げ役: 他プレイヤーの競走へ応援演出を送る

回数だけを要求する実績、連敗後の追い賭けを促す実績、高額BETを要求する実績は入れない。

## コインの楽しい吸収口

優先順位:

1. **共同建設基金**: 建設予定地が基礎、骨組み、開業へ段階変化する。
2. **港の演出**: 花火、紙吹雪、船砲、応援、ジュークボックス投票。
3. **柄コレクション**: BJカード裏、海賊じゃら牌裏、運命盤の縁、ダービー旗を横断テーマ化。
4. **大会参加料**: 短時間の定時イベントと結果掲示。
5. **船長サロン入場料**: 高い賭け上限と豪華な演出。数学的優位は付けない。
6. **交換手数料**: 経済調整役。楽しさの主役にはしない。

柄テーマ候補は `黒真珠`, `黄金航路`, `深海魔獣`, `幽霊船`, `南国祝祭`, `赤帆船団`。

共有卓全体を一人の設定で変更せず、自席、投票札、カード裏、牌裏、応援旗、ローカル結果演出を主な装着先にする。

## 共同建設

建設予定地への寄付は最も強い長期ループにする。

- Stage 0: 更地と計画看板
- Stage 1: 基礎と資材が出現
- Stage 2: 骨組みと試作遊具
- Stage 3: 正式開業、開業花火、寄付者銘板

寄付者へコイン配当は出さず、称号、旗、銘板、開業記念演出を付与する。コインが消えるのではなく風景へ変わる体験にする。

## 船長サロン

ハイリスク・ハイリターン区画は、一定の航海名声、複数ゲームの入門実績、入場料で開放する。

- 通常卓より5倍・10倍の賭け上限
- 確率、倍率、最大損失を入口で明示
- ランクやアイテムによる勝率上昇はなし
- 制限ルール卓、日次大会、観客向け勝利演出
- 共通コインを直接賭けず、必ずカジノコインへ交換して使う

残高0時の10枚はこれまで通り受付受取とし、進行中BETなし、クールダウン、一日上限、受取履歴を条件にする。

## アイテム連携

最初は所有証明による演出解放だけにする。

- 所持アイテムに対応する座席旗、投票札、カード柄、牌柄
- 特別な入場エフェクト、称号、撮影ポーズ
- アイテム展示用のトロフィー台
- テーマラウンジへの入場

勝率上昇、払戻増加、手数料優遇、無料再抽選は行わない。外部規格に所有権照会があると確認できてからAdapterを追加する。

## BGMアートディレクション

第一候補は **明るい海賊カーニバル × エレクトロスウィング**。

- 116〜124 BPM
- 長調またはミクソリディアン
- ブラス、クラリネット、マリンバ、ウッドベース、軽いドラム、手拍子
- ボーカルなし、低音ドローンなし、不穏な短調進行なし
- 90〜180秒のシームレスループ
- 音数は薄めにし、遊技SEと実況を主役にする

検索語:

- `upbeat pirate casino electro swing royalty free loop`
- `bright brass marimba arcade game music loop`
- `pirate carnival swing instrumental game bgm`
- `陽気 海賊 カジノ BGM ループ 商用利用`
- `明るい エレクトロスウィング ゲーム BGM`

ライセンスは商用ゲーム利用、編集・ループ加工、ゲーム/CDN同梱、クレジット、Content IDを確認する。ステム付きが理想。

共通BGMへゾーンSEを重ね、複数曲を同時再生しない。TTS中は100〜150msで約8dB下げ、350〜500msで戻す。実況情報は必ず字幕も表示する。
