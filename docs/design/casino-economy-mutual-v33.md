# RIF相互交換・カジノ経済 v33

管理側承認に基づき、`1 RIF = 両替可能カジノコイン50枚` を入金・出金で同率適用する。JST日付ごとに入金と出金の合計交換量を5 RIFまでに制限し、相殺はしない。1回の操作上限も5 RIFとする。

旧残高、救済10枚、運営配布、監査前ゲームの配当は `bonus` としてRIFへ出金できない。旧 `casino.coins.v1` は初回移行後に読み取り専用とし、`casino.wallet.v2` だけを正本にする。RIF入金は `redeemable` へ入り、ブラックジャック・船長の運命盤・海賊魔獣ダービーではBET原資を記録して払戻先を同じ比率へ戻す。混合BETで端数が出る場合、両替可能分を切り下げ、端数をbonusへ送るため換金価値は増えない。

麻雀は着席1回の支払いで次局を反復できる旧構造が残っていたため、ルールと精算監査が終わるまで無料・配当なしへ隔離した。アニマルじゃらβも無料を維持する。

交換はplayer KVのpending journalと、RIFCoinの `worldId + clientTransactionId` 冪等性を組み合わせる。入金はRIF支払い後にwalletへ反映し、出金はredeemableを先に引いてからRIFを付与する。通信失敗時は同じ方向・同じ額・同じIDで再試行する。ゲームBETも参加確定ごとにランダムIDを一度だけ生成し、共有ラウンド状態へ保存してインスタンス再生成時のラウンド番号衝突を避ける。

RIFCoin v0.1は認証を持たず、`userId` と `worldId` をクライアント申告として信頼する。World Storageも会計正本や認証にはならない。したがって本機能は非換金のXRiftゲーム通貨としてのみ扱い、管理区画の累計値は観測用とする。
